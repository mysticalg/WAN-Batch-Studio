Full setup & workflow requirements ↗
  1. Install WAN Batch Studio

    Download and run the Windows installer.

  2. Prepare ComfyUI + FFmpeg

    Start your server with your models. Install FFmpeg/ffprobe on PATH if needed.

    winget install --id Gyan.FFmpeg -e
  3. Import an API workflow

    Export Save (API Format) from ComfyUI. Choose images and segment count, then Start / Resume.

A few useful details

New frame PNGs go in frames/; final joined clips go in joined/. Installed user data stays in %LOCALAPPDATA%\WANBatchStudio and is retained when uninstalling.

Colour matching can reduce small global shifts. It does not guarantee sharpness or remove model/VAE reconstruction changes. Supported workflow requirements are documented on GitHub.

This first release is unsigned. Windows may display an unknown-publisher prompt; compare the installer with the SHA-256 checksum in the release before installing.
