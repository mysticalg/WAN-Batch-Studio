WAN Batch Studio 1.0.1

Documentation and Windows installer: https://mysticalg.github.io/WAN-Batch-Studio/
Source and releases: https://github.com/mysticalg/WAN-Batch-Studio

Requires your own running ComfyUI server, API workflow and models, plus FFmpeg/ffprobe on PATH. Python and app libraries are included in the Windows installer.

Installed user data: %LOCALAPPDATA%\WANBatchStudio
Original source images and generated segment videos are preserved. New frame PNGs go in outputs/frames; final joined clips go in outputs/joined.

Read README.md for setup, recovery, colour-matching limits, and source build instructions.
