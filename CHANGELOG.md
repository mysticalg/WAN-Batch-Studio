# Changelog

## 1.0.0

- Sequential ComfyUI image-to-video continuations, with a lossless pre-encoding final PNG for supported workflows.
- Editable main positive prompt and future segment additions; submitted work remains protected.
- Optional bounded colour matching, preserving original media.
- Pause after current, offline local reset, idle-only queue clearing, and ownership-scoped cancellation.
- Durable queue writes, two validated backups, startup corruption recovery, logs and render timers.
- Separate frames and joined output folders.
- Windows installer with bundled Python, per-user data directory and offline packaging self-test.
